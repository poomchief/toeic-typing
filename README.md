# พิมพ์ศัพท์ TOEIC ⌨️

เกมฝึกพิมพ์สัมผัสด้วยคำศัพท์ TOEIC เล่นบนเว็บได้ทันที ไม่ต้องติดตั้งอะไร
ทำโดย **PULULU** มี PU กับเฉาก๊วยคอยเชียร์ตลอดเกม

**▶ เล่นเลย: https://poomchief.github.io/toeic-typing/**

เจอปัญหาหรือมีไอเดีย แจ้งได้ที่ [Issues](https://github.com/poomchief/toeic-typing/issues/new/choose)

## มีอะไรในเกม

- **อาคาร TOEIC 20 ชั้น** ปลดล็อกทีละชั้น ยิ่งขึ้นสูงยิ่งหรู มีลิฟต์พา PU กับเฉาก๊วยขึ้นไปชั้นล่าสุด
  - ชั้น 1–6 ฝึกตามหลักภาษา: คำนาม กริยา คุณศัพท์ กริยาวิเศษณ์ ตระกูลคำ วลี
  - ชั้น 7–20 ฝึกตามหัวข้อธุรกิจ: อาคาร บริการลูกค้า ร้านค้า บุคลากร สุขภาพ การผลิต ไอที เทคโนโลยี สื่อ การตลาด อีเวนต์ การเงิน การเดินทาง โรงแรม
- **ดาดฟ้า: คำใหม่ประจำสัปดาห์** เปลี่ยนชุดละ 10 คำทุกวันจันทร์
- **3 โหมด**: ฝึกนิ้ว · ทดสอบสะกด · พิมพ์ประโยค
- จับเวลา 60 วินาที / 2 นาที หรือเล่นจนครบชุด
- คู่มือวางมือบนแป้นพิมพ์ วอร์มนิ้วก่อนเริ่ม และไฟบอกนิ้ว
- เสียงคีย์บอร์ด 2 แบบ เสียงอ่านคำศัพท์ โหมดสว่าง/มืด
- คำศัพท์รวม 465 คำ พร้อมคำแปลไทย ชนิดคำ และประโยคตัวอย่าง

ความคืบหน้าและสถิติเก็บไว้ในเบราว์เซอร์ของผู้เล่นแต่ละคน ไม่มีการส่งข้อมูลออกไปที่ไหน

## ไฟล์ในโปรเจกต์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (ไฟล์เดียวจบ) |
| `CHANGELOG.md` | บันทึกว่าแต่ละเวอร์ชันเพิ่มหรือแก้อะไร |
| `.github/ISSUE_TEMPLATE/` | แบบฟอร์มแจ้งปัญหาและเสนอไอเดีย (ภาษาไทย) |

## ตั้งค่าแบรนด์และปุ่มฟีดแบ็ก

เปิด `index.html` แล้วหา `const BRAND={` (อยู่ต้นส่วน `<script>`) แก้ได้ที่จุดเดียว:

- `url` — ลิงก์ร้านหรือช่อง
- `cta` — ข้อความบนปุ่มแบรนด์
- `logo` — ชื่อไฟล์โลโก้ เช่น `logo.png` (อัปโหลดรูปไว้ในโฟลเดอร์เดียวกัน)
- `feedback` — ลิงก์รับฟีดแบ็ก ใส่แล้วปุ่ม "💬 แจ้งปัญหา / เสนอไอเดีย" จะโผล่ท้ายหน้าเกม
  - ถ้า repository เป็น Public: `https://github.com/poomchief/toeic-typing/issues/new/choose` (ตั้งไว้ให้แล้ว)
  - ถ้า repository เป็น Private: ใช้ลิงก์ Google Form แทน (คนนอกส่ง Issue ใน repo ส่วนตัวไม่ได้)

ใต้ `BRAND` มี `APP_VERSION` ให้เปลี่ยนเลขทุกครั้งที่อัปเดต เลขนี้จะโชว์ท้ายหน้าเกม ผู้เล่นจะได้บอกได้ว่าเจอปัญหาในเวอร์ชันไหน

## อัปเดตเวอร์ชันใหม่

1. แก้ `index.html` และเปลี่ยน `APP_VERSION` เช่น จาก `1.0.0` เป็น `1.1.0`
2. เขียนสิ่งที่เปลี่ยนไว้บนสุดของ `CHANGELOG.md`
3. ใน GitHub กด **Add file → Upload files** ลากไฟล์ที่แก้ทับของเดิม
4. ช่อง commit message เขียนสั้น ๆ เช่น `v1.1.0 แก้บั๊กลิฟต์`
5. (ไม่บังคับ) เมนู **Releases → Draft a new release** ตั้ง tag เป็น `v1.1.0` เพื่อเก็บเวอร์ชันสำคัญ

ย้อนดูหรือดาวน์โหลดเวอร์ชันเก่าได้ทุกเมื่อจากปุ่ม **History** ของไฟล์

### หลักตั้งเลขเวอร์ชัน

- `1.0.1` — แก้บั๊กเล็ก ๆ
- `1.1.0` — เพิ่มฟีเจอร์หรือคำศัพท์
- `2.0.0` — เปลี่ยนใหญ่ เช่น ระบบด่านใหม่ทั้งหมด
